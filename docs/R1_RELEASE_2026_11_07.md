# Research artifact release — November 7, 2026

This update makes two distinct resources available: (1) Android multimodal label-logger source (`android/IndoorOutdoorDetection/`) and (2) six de-identified smartphone field recordings (`data/datasets/public_2026_11_07/`).

The datasets are research collection examples and do not belong to the reviewed primary-literature corpus of 108 reports/105 evidence families. The data README documents sensor fields, missing streams, de-identification, checksums, labeling limitations, and usage boundaries. Application source is not claimed to have a recently verified clean-room build; see Android README.

The release comprises 6 sessions, 154.8 minutes, and 120 labeling events, across 14 CSV streams per session. Some streams are empty or sparse depending on collection conditions.

Public de-identification does not guarantee anonymity; confirm rights, consent, and institutional release approvals before publishing.
